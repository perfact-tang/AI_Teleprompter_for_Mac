## 基础美颜功能验证

- 使用 Apple Vision 关键点与 Core Image 实现局部磨皮和脸颊形变；美颜视频帧在预览与录制的分流之前生成。
- Release 应用和原生 Xcode 工程构建通过。启动应用，打开美颜面板，验证开关、强度滑杆、原图对比入口及布局。
- 共 17 项测试通过（含显式提供本地人脸图片的集成测试）。像素测试确认零强度 / 关闭原样输出、磨皮确实降低局部纹理、眼睛和背景保留、瘦脸局部位移与中心保护。
- 使用用户先前提供的截图作为临时人脸输入，实际执行 Vision 检测，生成 1280×720 美颜帧，验证默认预览 / 录制使用同一帧、对比原图只切换预览、原始时间戳及帧时长保留。
- 将处理后画面写成 15 帧 H.264 MOV，解码回读，确认时长约 0.5 秒，解码像素与美颜输出更接近，而不是原图；对处理前后 PNG 做了人工视觉检查。输入截图没有复制到仓库，验证输出只保存在系统临时目录。
- 检查关闭效果、丢失人脸后的回退。检测 / 预览 / 输出像素缓冲均有界，避免每帧新增无界任务。
- 尚未代替真人摄像头试录和长时间运行测试；特别是美颜 + Whisper 并发性能、多次暂停后的音画同步，按清单 E 在目标机器继续验收。像素渲染耗时不等于完整采集 / 检测 / 预览的端到端延迟。

开发说明：自定义 Core Image 内核目前使用系统仍支持的运行时 Kernel Language 入口（已被系统标记弃用）；当前系统的真实内核渲染测试通过。将来升级系统时需复验，后续可迁移为预编译 Metal 内核。

## 扩展美颜与滤镜验证

- 对照美图官方人像 / 滤镜介绍与面部重塑说明，补充独立的小脸、小头、窄脸、颅骨（二维颅顶）、短脸、大眼、瘦鼻、鼻头、嘴型，并保留旧磨皮、瘦脸。调研来源与各项范围见 `APPEARANCE.md`。
- 新增自然、清透、冷白皮、高清四种独立调色配方，连续强度混合及曝光 / 对比 / 饱和 / 冷暖。调色不依赖人脸，不受人脸总开关限制；原图对比只切换预览。
- 完整运行 27 项测试，全部通过且无跳过。包含每个形变的独立位移、方向、零值、嘴型正负、远处背景、极端叠加、配方差异、强度连续性、冷暖与曝光方向、无脸调色、JSON 序列化。
- 使用用户先前提供的本地截图实际运行 Vision，在同一张正面人脸上分别生成磨皮、瘦脸、九个新形变、四款滤镜与组合效果，共 16 个处理样本。逐一写入 H.264 MOV 后解码，每个样本的解码像素均更接近对应处理结果而不是原图。内部对照图已视觉检查；个人照片未复制到仓库。
- 添加处理后 sRGB 像素缓冲色彩附件，并给正式 H.264 写入器配置 BT.709 属性，明确 RGB 到录像的色彩转换，不靠未标记缓冲的默认猜测。
- 使用既有本地测试片段，所有新增形变以 35% 叠加、同时磨皮 / 瘦脸及清透调色，以 30 fps 连续编码 180 帧，预热后 150/150 帧均成功处理，未出现持续原图回退。片段不足时保持最后一帧；这不是长时间运动真人测试。
- 原生 Xcode Debug 工程构建通过，Release 独立应用构建和签名通过。已实际打开三个标签页，确认所有滑杆、归零入口、原图开关和滤镜按钮存在且布局可用；长内容滚动显示。

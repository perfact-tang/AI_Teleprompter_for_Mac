# 本机验收清单

在目标 M2 / 24GB 上执行。下列项目是待人工验证的验收步骤，不能用构建通过代替。记录 macOS、Xcode、whisper.cpp 版本、模型、语言、录制时长和结果。

## A 基础录制

- [ ] 初次开启摄像头，分别允许摄像头与麦克风；确认画面和声音正常。
- [ ] 拒绝任一权限，确认有中文提示；到系统设置授权并重开后可用。
- [ ] 没有摄像头 / 麦克风或设备被占用时，显示错误且可以重试。
- [ ] 导入 UTF-8 TXT、MD 和含 emoji 的稿件；Markdown 按纯文本显示，非 UTF-8 给出提示。
- [ ] 调整字号、位置和底色；最小窗口下操作仍可用，长稿可滚动。
- [ ] 提词段落及换行文字居中；拖动顶部移动、右下角缩放均可用，框体不越出预览或遮挡底部录制状态。改变窗口大小后仍在预览内；点击“复位”恢复居中，重启保留位置及大小。
- [ ] 关闭自动跟随，录制 30 秒。用 QuickTime 打开文件，确认 H.264 视频和 AAC 音频正常、**没有提词文字**。
- [ ] 取消保存后点击“保存视频”成功重试；取消后退出，重新打开恢复目录能找到已完成的视频。
- [ ] 目标文件已存在时取消替换不影响原文件；允许替换后新文件可播放。

## B 暂停与异常

- [ ] 录制 5 秒 → 暂停 10 秒 → 继续 5 秒 → 结束；成片约 10 秒，暂停没有黑帧或静音空段。
- [ ] 多次执行不同长度暂停，分别在恢复前后拍手，确认声音与动作同步。
- [ ] 刚开始立刻暂停 / 继续，连续快速切换，暂停状态直接结束，均能正常保存。
- [ ] 录制 10 分钟，包含 10 次暂停；首尾拍手同步，文件可拖动播放，时长符合实际录制时间。
- [ ] 正常关闭窗口 / ⌘Q 提示先结束录制；取消退出后可继续；结束保存后退出。
- [ ] 设备断开 / 采集会话被中断时有错误提示；可结束保存已有内容。
- [ ] 在专用测试磁盘环境验证低空间暂停、目标无写权限和保存失败；不要填满日常系统盘。
- [ ] 模拟强制退出后检查恢复目录；允许未完成 MOV 不可播放，但不得清理原有已完成文件。

## C Whisper 与离线

- [ ] 工具 / 模型缺失、路径错误、误选 .en 模型，自动跟随启动被阻止；关闭跟随仍能录制。
- [ ] base 多语言模型分别识别中文与日语；确认“识别动态”出现实际朗读内容。
- [ ] 切断网络后重启应用，分别录制一段中文和一段日文；识别与保存正常。
- [ ] 暂停时提词与计时停止，恢复不会接收暂停前的过期识别结果。
- [ ] 替换成损坏模型 / 不可执行工具，出现识别错误，视频录制可继续并保存。
- [ ] 使用 10 分钟稿件持续识别；无持续积压、无不断增长的音频缓冲。

## D 跟随与性能

- [ ] 正常语速、快读、慢读、停顿 10 秒、重复句、跳过一句、口误、风扇噪声和背景声音。
- [ ] 安静停顿时不推进；短误识别不突跳；过大跳句可以点击段落人工定位。
- [ ] 同一句多次出现时不会因重复识别结果一口气跳过多个位置。
- [ ] 片段切换时平滑滚动；从开头重置和手动定位后仍能继续匹配。

## E 基础美颜

- [ ] 右上角打开美颜，关闭时是原图；磨皮 / 瘦脸分别从 0 到 100 调节，有连续变化；强度重启后保留。
- [ ] 磨皮降低面部细小纹理，眼睛和嘴巴仍清晰；瘦脸轻微收拢左右脸颊，鼻子 / 嘴巴不明显变形。
- [ ] 对比原图时，预览恢复原图，保存后的视频仍有美颜；关闭美颜开关后，录制也恢复原图。
- [ ] 人离开画面、转侧脸、大幅歪头时回退原图；回到正面后恢复。多人进入时只处理最大的一张可靠正面人脸。
- [ ] 录制期间调整两项参数；连续多次暂停 / 继续；导出后确认美颜生效、声音正常且无提词文字。
- [ ] 美颜与 Whisper 一起运行至少 10 分钟，检查掉帧和内存。预览不积压，磁盘成片可播放且音画同步。
- [ ] 提词框移动 / 缩放和自动滚动不受美颜影响。较暗环境、眼镜、胡须和复杂背景下观察边界；大强度形变可能带动邻近背景。

## F 扩展美颜与滤镜

- [ ] 基础美颜逐项试磨皮、小脸、小头、窄脸、颅骨、短脸和旧瘦脸，变化区域不同，各项零值关闭。
- [ ] 五官逐项试大眼、瘦鼻、鼻头，嘴型负值缩小、正值放大。验证每项归零、本页归零、全部归零。
- [ ] 自然、清透、冷白皮、高清分别切换，强度从 0 调至 100 连续变化，高清不会改变导出分辨率。
- [ ] 曝光 / 对比 / 饱和 / 冷暖正负值可调；原色下手动调色仍有效；本页归零清除预设与手动调色。
- [ ] 关闭人脸总开关后滤镜仍工作；人离开画面后调色继续，并显示仅调色生效。
- [ ] 重启保留全部人脸参数、滤镜及手动调色；原图对比重置为关闭。
- [ ] 录像中切换预设、拖动参数，再多次暂停 / 继续；QuickTime 成片确实保留各段效果，声音同步，无提词 / 状态文字。
- [ ] 正常 / 偏暗 / 背光环境下对照预览与成片颜色。大眼、缩头与颅顶在运动和复杂背景下没有难以接受的拉扯。
- [ ] 所有效果与 Whisper 一起连续录制至少 10 分钟，记录 CPU / 内存 / 掉帧，避免仅以静态图测试代替实时性能验收。

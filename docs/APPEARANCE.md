# 美颜与滤镜说明

这版提供本地实时的人脸调整与滤镜调色，预览与录像共用处理链路。各项按人脸关键点定位，不修改稿件或音频。

## 调研依据与实现范围

美图官方将人像精修和滤镜调色作为不同能力；其面部重塑说明区分整体缩头与面部宽度调整。此处参考功能分类与视觉目标，自行实现二维形变和调色配方，**未接入美图 SDK、云端服务或原版 LUT，也不承诺与商业产品一比一一致**。

## 基础美颜

| 项目 | 作用区域与方向 | 强度 |
| --- | --- | --- |
| 磨皮 | 局部双边滤波平滑纹理，眼睛、嘴唇保持清晰 | 0–100% |
| 小脸 | 整体面部轻微收小，作用范围小于小头 | 0–100% |
| 小头 | 包括估计的头发包络区，轻微缩小头部 | 0–100% |
| 窄脸 | 横向收窄整张脸，区别于整体缩放 | 0–100% |
| 颅骨 | 抬高、饱满颅顶的二维投影形变 | 0–100% |
| 短脸 | 压缩中下庭，轻抬下巴 | 0–100% |
| 瘦脸 | 保留上一版独立的左右脸颊局部收拢 | 0–100% |

“颅骨”是颅顶外观调整，不是三维骨骼重建；上部头发区域由脸框推估。小头与颅顶可能带动邻近背景，适合单人、正面、光线充足的画面。多个项目叠加时限制总位移，避免极端拉扯，但仍建议逐项小幅调整。

## 五官调整

| 项目 | 作用 | 强度 |
| --- | --- | --- |
| 大眼 | 围绕左右眼关键点分别放大 | 0–100% |
| 瘦鼻 | 收窄鼻梁、鼻翼所在的局部区域 | 0–100% |
| 鼻头 | 以鼻尖关键点为中心局部收小鼻头 | 0–100% |
| 嘴型 | 负值收小，正值放大嘴唇轮廓 | −100–100% |

各项独立且零值完全关闭该项。人脸美颜总开关关闭时，这些形变与磨皮全部跳过，滤镜仍可单独使用。

## 滤镜与调色

| 方案 | 自行实现的视觉方向 |
| --- | --- |
| 原色 | 不叠加预设，仍可手动调色 |
| 自然 | 少量曝光、饱和与自然鲜艳度提升，保留自然肤色 |
| 清透 | 提亮阴影和中间调，柔和高光，增强通透层次 |
| 冷白皮 | 微冷白平衡、柔亮中间调和轻微降饱和 |
| 高清 | 适度对比、鲜艳度与反差锐化，增强清晰感；不提高分辨率 |

滤镜强度 0–100% 连续混合原图与预设结果。手动曝光、对比、饱和、冷暖在预设之后应用，各自范围 −100–100%，与滤镜强度独立。选择“原色”不会清除手动调色；“本页归零”会同时清除预设与手动调色。

全局调色不依赖人脸。无脸、明显侧脸或歪头时，人脸效果回退，但所选滤镜继续工作，界面明确显示“调色生效 · 未应用人脸调整”。没有任何效果时直接传递原始帧。

## 使用与持久化

右上角“美颜与滤镜”进入三个标签页：基础美颜、五官调整、滤镜调色。长面板可滚动。每项旁边的回转箭头归零该项；本页归零只清理当前分类，全部归零清除所有效果。原有磨皮 / 瘦脸参数沿用，新形变首次默认零，滤镜首次默认原色。

“预览原图对比”仅改变预览，录像仍使用当前美颜与调色。若需要录制完全原图，关闭人脸美颜，选择原色，并归零所有手动调色。所有参数保存在本机 UserDefaults；原图对比不跨重启保留。

处理后 RGB 帧标记 sRGB；H.264 输出使用 BT.709 颜色属性，减少预览和导出时因颜色空间猜测产生的偏差。视频依然为 720p，不烧录提词或状态文字。

## 验证方法

自动测试检查每个形变的独立像素位移、方向、远处背景保护、嘴型正负方向、零值、极端叠加限制、各滤镜独立效果与强度、冷暖 / 曝光方向、无脸调色及参数序列化。

设置本地正面图片和视频后，可运行真实 Vision、各效果 PNG 视觉检查、每项 H.264 写入 / 解码对照及 30 fps 连续编码验证：

```bash
BEAUTY_FACE_FIXTURE="/absolute/path/to/frontal-face.png" \
BEAUTY_VIDEO_FIXTURE="/absolute/path/to/local-video.mov" \
swift test --disable-sandbox
```

测试不自动采集摄像头，图片不复制到仓库。视觉校验图和短 MOV 输出到系统临时目录；日志给出路径与图块顺序。目标 Mac 的长时间真人录制、美颜与 Whisper 并发性能仍应按验收清单检查。
